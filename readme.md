# ПОРА ЛЕТЕТЬ | Интерактивный спецпроект

**ПОРА ЛЕТЕТЬ** — это научно-популярный веб-проект, визуализирующий осеннюю миграцию птиц из Российской Арктики. Проект наглядно показывает, как миллионы птиц покидают тундру, спасаясь от холодов, и расходятся по трем главным пролётным путям: Восточноатлантическому, Центральноазиатскому и Восточноазиатскому.

## 🛠 Технологии

*   **HTML5 / CSS3 / Vanilla JavaScript**
*   **[Tailwind CSS](https://tailwindcss.com/)** (подключен через CDN) — для быстрой стилизации интерфейса.
*   **[Leaflet.js](https://leafletjs.com/)** — для рендеринга интерактивной карты и анимации маркеров.
*   **CartoDB Dark Matter** — картографическая базовая подложка.

## 📊 Методология и Данные

Проект не использует сырые GPS-треки напрямую в браузере для сохранения высокой производительности. 

Данные генерализованы:
**Треки миграции** смоделированы на основе обобщенных пространственных данных и телеметрии из открытых баз **Movebank** (Arctic Animal Movement Archive) и **GBIF**. Маршруты привязаны к месяцам и математически интерполированы.

## 🚀 Установка и локальный запуск

Проект состоит из одного файла и не требует сборки (Webpack/Vite/Node.js).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_USERNAME/pora-letet.git
   ```
2. Откройте папку проекта.
3. Откройте файл `index.html` в любом современном браузере. 
   *(Рекомендуется использовать плагин Live Server для VS Code, чтобы избежать проблем с CORS при загрузке внешних ресурсов).*

### Настройка API-ключа карты
В проекте используется тайловый сервер CartoDB. Для продакшн-использования необходимо получить собственный бесплатный API-ключ.
1. Зарегистрируйтесь на [Carto](https://carto.com/) или аналогичном сервисе (Mapbox/Stadia).
2. Замените значение переменной `apiKey` в блоке скриптов:
   ```javascript
   const apiKey = "ВАШ_НОВЫЙ_КЛЮЧ"; 
   ```

## 📂 Структура данных (JSON)

Добавление новых видов осуществляется простым редактированием объекта `migrationData` внутри `index.html`. Для каждой птицы требуются 12 координат (по одной на каждый месяц):

```javascript
{
    name: "Название вида",
    color: "#HexColor",
    status: "Красная книга", // Опционально
    desc: "Описание птицы...",
    img: "URL_фотографии",
    track: {
        8: [Широта, Долгота], // Август
        9: [Широта, Долгота], // Сентябрь
        // ... до июля (7)
    }
}
```

## 📄 Лицензия

Иллюстрации птиц и дизайн интерфейса разработаны специально для данного проекта. При использовании геоданных и концепции ссылайтесь на первоисточники (Movebank, GBIF).
